tthq

tthq is a personal command line and localhost tool that prepares gameplay clips for TikTok and uploads them to the operator's own TikTok account. It encodes each clip once with ffmpeg to TikTok's recommended specification (H.264 High, AAC audio, 9:16 or 16:9) so the clip is not compressed twice, then posts it either through TikTok Studio in a browser session or through TikTok's Content Posting API.

It runs entirely on the operator's own machine, posts only to the account that authorized it, and is not a hosted service.

Source code: github.com/sadafdfafafa/tthq
