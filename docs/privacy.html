Privacy Policy

Last updated: 12 August 2026

1. No servers, no collection

tthq runs entirely on the user's own computer. It has no backend service, no analytics, and no telemetry. The author receives no data from it. Nothing is transmitted anywhere except directly to TikTok, on the user's instruction.

2. What is stored, and where

  • Video files - read from, and written to, folders the user chooses on their own machine.
  • TikTok access and refresh tokens - stored in ~/.cache/tthq/tiktok_token.json with owner-only permissions, used only to call TikTok's API on the user's behalf.
  • Browser cookies (optional, browser upload mode only) - read from a file the user exports themselves, used only to restore their TikTok session in a local browser.
  • Screenshots of the upload page, saved locally so failed uploads can be diagnosed.

All of this stays on the user's machine and can be deleted at any time.

3. Data shared with TikTok

When the user starts an upload, the video file and the caption, hashtags and privacy setting they entered are sent to TikTok. With TikTok's API, the software also reads basic account information (user.info.basic) and the account's allowed privacy options, in order to post correctly. TikTok's handling of that data is governed by the TikTok Privacy Policy.

4. Revoking access and deleting data

Access can be revoked at any time from TikTok's app or account settings. Deleting ~/.cache/tthq/ and the cookie file removes every credential the software stored. Since no data is held anywhere else, no deletion request to the author is necessary.

5. Children

The software is not directed at children under 13 and collects no data from anyone.
