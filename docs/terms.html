1. What tthq is

tthq ("the software") is a free, open source tool that runs on the user's own computer. It re-encodes video files with ffmpeg and uploads them to the user's own TikTok account, either through TikTok Studio in a browser session or through TikTok's Content Posting API after the user authorizes the software.
